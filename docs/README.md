# Project documentation

Keep reviewed technical decisions and reproducibility notes here.

- `decisions/`: approved decisions with date, alternatives, rationale, and
  source references.
- `architecture.md`: tier diagram, components, and data flow.
- `data-dictionary.md`: source and warehouse fields, types, meanings, keys, and
  table grain.
- `reproducibility.md`: environment, setup, pipeline run steps, and expected
  output locations.

Do not treat a proposed design as implemented until the repository contains
the implementation and verification evidence.
