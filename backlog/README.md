# Project backlog

Use this folder to keep AI-assisted and team work scoped, reviewable, and
connected to course deliverables.

## Folders

- `tasks/`: agreed work that is ready or in progress.
- `drafts/`: questions and candidate tasks that need a decision or more scope.
- `completed/`: completed work with updated acceptance criteria and evidence.
- `archive/`: superseded or cancelled records retained for history.
- `templates/`: blank task format.

## Workflow

1. Put unresolved questions in `drafts/`; do not present them as approved work.
2. Move approved work into `tasks/` and set its status to `To Do`.
3. Before substantial changes, set the status to `In Progress` and confirm
   scope and acceptance criteria.
4. After implementation, record changed files, verification performed, and
   unresolved limitations.
5. Move only genuinely complete tasks to `completed/` and set status to `Done`.

Do not mark planned work as verified. For this academic project, the course
brief's requirements and instructor clarifications belong in the task context.

## Task IDs

Use sequential IDs (`TASK-001`, `TASK-002`, ...). Preserve an existing ID when
renaming or moving a task. Suggested filename:
`task-001-short-descriptive-name.md`.
